# Gemini adapter

Shared context starts with the project brief, status and [Rules](../../rules/index.md); reusable workflows live in [Skills](../../skills/index.md). This catalog does not install or certify a Gemini runtime.

Before using a particular local or remote client, establish how it loads instructions, discovers skills, connects tools and exports conversations. The existing Google meeting-transcript importer is a source integration, not a Gemini agent runtime. Native authentication, permissions and automation stay with their actual runtime.
